A chess engine in under 4 KB of Python: a 0x88 board, negamax search with quiescence, MVV-LVA move ordering and piece-square tables, iterative deepening under a fixed node budget — deterministic, standard library only, speaking the make.fun env protocol (game state and legal moves over HTTP).

## Run it

```sh
MAKEFUN_ENV_URL=<env url> python3 main.py
```
